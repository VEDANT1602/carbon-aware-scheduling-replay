# Data sources, attribution and transformations

The third-party files below retain their source permissions. See NAB-LICENSE for the legacy NAB request-count file. All newly created input subsets contain only the selected quantitative fields.

| Included derivative | Creator, source and terms | Transformation |
| --- | --- | --- |
| archer2_allocations.csv and repeat_week/ equivalent | Adrian Jackson and Ioannis Lamprakis. *HPC System Usage Data*, v1.0. [Zenodo](https://doi.org/10.5281/zenodo.14284189). [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). | Selected positive elapsed node allocations intersecting each evaluation week plus two drain hours. Re-encoded start/end as integer UTC seconds; removed record ID, CPU count and unrelated fields. |
| gb_intensity.csv and repeat_week/ equivalent | National Energy System Operator, Carbon Intensity API for Great Britain. [Source and terms](https://carbonintensity.org.uk/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). | Retained national half-hour actual estimates and archived forecast values and converted UTC starts to integer seconds. Changed file format from JSON to CSV. See exact interval requests below. |
| archer2_meter_calibration.csv | Andrew Turner and Alastair Basden, *HPC-JEEP: Energy Usage on ARCHER2 and the DiRAC COSMA HPC services dataset*, v1.0. [Source](https://doi.org/10.5281/zenodo.7128646). | Reports counts and three aggregate quantiles calculated from March 2022 completed ARCHER2 job steps with positive node count, elapsed seconds and measured joules. Original archive and software were not redistributed. The project report documents missing meters and measurement boundaries. |
| reservation_audit.csv | GWA-T-2 Grid5000, contributed by Alexandru Iosup and Mathieu Jan. We acknowledge the Grid’5000 team, in particular Franck Cappello; the OAR team, in particular Olivier Richard and Nicolas Capit; and the Grid Workloads Archive for providing the traces. [Source and attribution terms](https://atlarge-research.com/gwa-t-2/). | Contains only aggregate counts after joining Jobs_Reservation to Jobs on JobID. The French years and site are distinct from the British replay. |
| dated_results.csv, dated_daily.csv, primary_start_choices.csv and repeats | Counterfactual calculations based on the above sources. | Dates, reservations, hardware meter distributions and grid values have separate provenance. Job-level energy and user deadlines are not observed in the dated schedule. |

- NESO [primary request](https://api.carbonintensity.org.uk/intensity/2022-03-05T00:00Z/2022-03-15T00:00Z), SHA-256 c1c4f68601eaf8776d52016d9cb4ee462daad64fdd651c6e44541eb2a10cf1e4; [repeat request](https://api.carbonintensity.org.uk/intensity/2022-03-12T00:00Z/2022-03-22T00:00Z). Repeat SHA-256 67976f84661aaeea455c93d7c6ec345aa6a00e0d9dddead78b8e31c81595a7fc. These intervals include pre-period data and drain hours. Forecast values in this endpoint carry no issue-time field.

The local host exposed no /sys/class/powercap, energy_uj counter, /dev/cpu/*/msr or power sensor. No power was inferred from CPU time. The March job-step meter calibration is external to the host and measures compute energy, not the cost of forecast lookup.
